## 2. 构建命令

本机有两个特殊限制，因此**必须带 `-s .mvn/settings.xml`**：

```bash
# 全量构建（跳过测试）
mvn -s .mvn/settings.xml clean package -DskipTests

# 全量构建（含测试）
mvn -s .mvn/settings.xml clean package

# 只构建某个服务及其依赖
mvn -s .mvn/settings.xml -pl smart-product -am clean package -DskipTests
```

### 为什么必须用 `.mvn/settings.xml`

| 问题 | 现象 | 解法 |
|---|---|---|
| `~/.m2/repository` 只读 | Maven 写 `_remote.repositories` 时抛 `AccessDeniedException` | settings 里把 `localRepository` 指向工作区内的 `.mvn/repo`（由 `.m2/repository` 复制而来） |
| 直连外网 TLS 失败 | `AcquireCredentialsHandle failed / 基础连接已经关闭` | 本机 `127.0.0.1:7890` 代理可用，settings 里配了 `<proxies>`，Maven 走代理下载 |
| 缓存来源 id 混杂 | 部分构件记录为 `central`，部分为 `aliyunmaven`，离线模式报 `present, but unavailable` | 复制仓库时清除了 `_remote.repositories` 标记 |
| JDK 21 javac 不自动跑注解处理器 | Lombok 的 `@Data`/`@Slf4j` 静默失效，报"找不到符号 getCode()/log" | 父 pom 显式配置 `annotationProcessorPaths` + `annotationProcessors` |

> `.mvn/repo` 约 0.7GB，已在 `.gitignore` 中排除，**不要提交仓库**。
> 换机器/网络正常时，删掉 `.mvn/settings.xml` 或用默认 settings 即可。

## 3. 数据库初始化

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
$files = @("00_create_databases.sql","01_schema_product.sql","02_schema_production.sql",
           "03_schema_inventory.sql","04_schema_quality.sql","05_schema_system.sql","06_init_data.sql")
foreach ($f in $files) {
  Get-Content "sql\$f" -Raw -Encoding UTF8 |
    & $mysql -uroot -p123456 --default-character-set=utf8mb4
}
```

**注意**：`00_create_databases.sql` 会 `DROP DATABASE`，重复执行会清空数据。

## 4. 启动服务

本机未启动 Nacos，单服务运行时可关闭注册：

```powershell
java -jar smart-product/target/smart-product-1.0.0.jar `
  --spring.cloud.nacos.discovery.enabled=false
```

Nacos 启动后可直接 `java -jar ...`，服务会自动注册到 `MES_GROUP`。
